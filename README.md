# AI 专家系统 (AI Advisor System)

一套基于多 Agent 协作的高考志愿决策辅助系统，适配 Android (Termux) 与 Ubuntu 环境。

## 🌟 特性
- **多 Agent 协作**：集成 Qwen, MiMo, Kimi, DeepSeek, Claude 等多个顶级模型。
- **极客视觉交互**：基于 Rich 库实现的克劳德风格律动动画与流式交互。
- **环境自适应**：一键部署，自动识别 Termux 原生环境或 Ubuntu 容器。
- **安全加固**：内置文件上传安全校验与 API 异常重试机制。

## 🚀 快速开始
在您的终端执行以下命令：
```bash
bash setup.sh
```
